## Recording policy

A bug requires observed behavior, expected behavior, reproduction steps, environment, affected version, and evidence. Assumptions, architecture risks, missing planned work, and requested scope changes do not belong here.

Use `docs/RISKS.md` for prospective failure, `docs/ASSUMPTIONS.md` for unverified beliefs, a change request for newly required work, and the planning-error ledger for missed planning.
