Plain-language policy

Privacy

The core pasted-HTML scanner runs in your browser. MachineCart does not need an account to produce the result.

Pasted HTML

When you paste page source into the scanner, the analysis is performed by JavaScript in your browser. The page stores the latest result and a local completion count in browser local storage so you can recover the most recent result on that device.

URL retrieval mode

Browsers generally prevent a static website from directly retrieving arbitrary stores. URL mode therefore sends the public URL to a third-party CORS retrieval service. Do not use URL mode for private, authenticated, unpublished, or sensitive pages. Paste HTML instead when confidentiality matters.

Email and audit requests

If you select an email link, your email application creates a message addressed to the business owner. The contents are not sent until you choose to send that email. Information in an audit request is used to respond to the request and deliver the requested work.

Analytics

The first release does not embed advertising trackers. Aggregate first-party analytics may be added later to understand scanner starts, completions, conversions, and product usefulness. This page will be updated before materially different collection begins.
