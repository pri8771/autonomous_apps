A variant is a purchasable record, not just a label

Each purchasable combination should resolve to the correct identifiers, price, stock state, image, and URL behavior. A generic parent record is not enough when the actual offer changes by selection.

Look for silent mismatches

Common failures include a selected color with the parent image, an out-of-stock size marked available in structured data, duplicate SKUs, and price ranges that do not match the chosen option.

Test shareable states

When possible, a selected variant should have a stable URL or another reliable state representation. A shopper or agent should be able to return to the same purchasable configuration.
