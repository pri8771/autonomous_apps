Plain-language policy

Privacy

The core pasted-HTML scanner runs in your browser. CommerceLint does not need an account to produce the result.

Pasted HTML

When you paste page source into the scanner, the analysis is performed by JavaScript in your browser. The page stores the latest result and a local completion count in browser local storage so you can recover the most recent result on that device.

URL retrieval mode

Browsers generally prevent a static website from directly retrieving arbitrary stores. URL mode therefore sends the public URL to a third-party CORS retrieval service. Do not use URL mode for private, authenticated, unpublished, or sensitive pages. Paste HTML instead when confidentiality matters.

Email and audit requests

If you select an email link, your email application creates a message addressed to the business owner. The contents are not sent until you choose to send that email. Information in an audit request is used to respond to the request and deliver the requested work.

Optional analytics

CommerceLint loads Google Analytics 4 only after you select Allow analytics. Before that choice, no Google Analytics script is requested and no analytics event is sent.

When enabled, CommerceLint sends the sanitized page path without query strings, broad scanner outcome bands and counts, offer or CLI interest clicks, evidence-download events, and lead-start events. It does not send pasted HTML, scanned product URLs, titles from scanned stores, scan evidence, email addresses, or form contents.

CommerceLint events use the cl_ prefix and are separated by the priyanshchordia.com hostname in an owner-controlled Google Analytics account. Advertising storage, Google signals, ad personalization, and ad-user-data consent remain disabled.

Your preference is stored in this browser. Global Privacy Control or Do Not Track disables analytics. You may change the preference below at any time.

Google processes consented analytics data under its own privacy terms. CommerceLint uses the data to measure page paths, scanner completion, offer interest, and acquisition sources.
