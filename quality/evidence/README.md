# Quality Evidence

Store small, durable evidence indexes here. Large logs, screenshots, `.xcresult` bundles, videos, model files, and browser traces normally remain in Application Support or CI artifacts.

Every record identifies feature, task, revision, scenario, environment, tool versions, date, result, verifier, sensitivity, checksum when applicable, and artifact location.

A missing check is `verification_pending`, not passed. Evidence must be redacted and must never contain raw credentials.
