# Canonical Local App Factory Rules

This repository follows `pri8771/iOS_app_factory_rules` standard version `0.4.0`.

Before editing, follow the repository map and read only task-relevant canonical documents. Use reuse-first development for cross-cutting infrastructure. Work on feature branches from `dev`; promote validated work from `dev` to `qa`, then from `qa` to `main` through reviewed pull requests.

No task is complete without its required build, test, review, and acceptance evidence. New necessary work must be recorded as a change request, and planning omissions must be recorded for future improvement.
